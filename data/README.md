# Data Directory

This folder stores the data files used for the project.

## Dataset

- Dataset: Credit Score Classification
- Source: Kaggle
- Task: Multi-class Classification
- Target: `Credit_Score`
- Classes: `Good`, `Standard`, `Poor`
